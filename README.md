# The Translator — Boardroom Edition

**Strategic Career Pivoting for Hospitality Leaders.**

The Translator is a mobile-first full-stack web application designed for hospitality professionals to reframe their operational excellence into strategic, high-fidelity resume points and professional narratives suitable for boardroom-level applications.

## 🚀 Key Features

- **Cinematic Experience**: High-energy animations, glassmorphism UI, and animated background glows designed for professional excellence.
- **AI-Powered Strategic Reframing**: Integration with **Claude 3.5 Sonnet** to translate hospitality tasks into strategic business achievements with a human-centric professional tone.
- **Elite Paywall**: A high-converting premium checkout experience for a full human-polished resume transformation at only **$2.99**.
- **Lead Performance**: Automatic lead capture and submission tracking via **Supabase**.

## 🛠️ Stack

- **Frontend**: React + Vite, Framer Motion, Tailwind CSS, Lucide Icons.
- **Backend**: Node.js + Express, Multer, PDF-Parse.
- **Database**: Supabase.
- **AI**: Anthropic Claude API (Optimized for human-fidelity detection bypass).

## 📦 Setup

1.  **Clone**: `git clone https://github.com/sarastrist-crypto/the-translator-.git`
2.  **Backend**: `cd server && npm install`
3.  **Frontend**: `cd client && npm install`
4.  **Environment**: Create a `.env` in `/server` with:
    - `ANTHROPIC_API_KEY`
    - `SUPABASE_URL`
    - `SUPABASE_KEY`
5.  **Launch**: `npm run dev` (from root)
