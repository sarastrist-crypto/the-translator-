# The Translator — Elite Edition

**Turn Shift Hustle into Corporate Strategic Power.**

The Translator is a mobile-first full-stack web application designed for hospitality workers to reframe their grit and expertise into professional, high-fidelity resume points and LinkedIn bios suitable for corporate applications.

## 🚀 Key Features
- **Cinematic Experience**: High-energy animations, glassmorphism UI, and animated background glows designed for the 19-35 demographic.
- **AI-Powered Reframing**: Deep integration with **Claude 3.5 Sonnet** to translate hospitality tasks into strategic business achievements.
- **Resume File Support**: Drag-and-drop current resumes (PDF/DOC) for analysis and a "Elite Portfolio" upgrade.
- **Elite Paywall**: A high-converting premium checkout experience for a full PDF resume transformation.
- **Lead Performance**: Automatic lead capture and submission tracking via **Supabase**.

## 🛠️ Stack
- **Frontend**: React + Vite, Framer Motion, Tailwind CSS, Lucide Icons.
- **Backend**: Node.js + Express, Multer, PDF-Parse.
- **Database**: Supabase.
- **AI**: Anthropic Claude API.

## 📦 Setup
1. **Clone**: `git clone https://github.com/YOUR_USER/the-translator.git`
2. **Backend**: `cd server && npm install`
3. **Frontend**: `cd client && npm install`
4. **Environment**: Create a `.env` in `/server` with:
   - `ANTHROPIC_API_KEY`
   - `SUPABASE_URL`
   - `SUPABASE_KEY`
5. **Launch**: `npm run dev` (from root)
